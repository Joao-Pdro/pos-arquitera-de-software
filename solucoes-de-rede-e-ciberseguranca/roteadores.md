# Roteadores

define o caminho que um pacote deve fazer para sair de um ponto A e chagar até um ponto B. e ele trabalha com tabelas de rotas.

### Metodos de atualização de rotas:
 - Estática: envolve a atualização manual das tabelas de rotas.
 - Dinamica: os roteadores dinamicos trocam automaticamenteinformaçoes com dispositivos a partir de diferentes protocolos de roteamento
